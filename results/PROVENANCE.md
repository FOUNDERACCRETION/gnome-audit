# Provenance of the files in this directory

Everything here is regenerated by `python run_all.py` from the two GNoME CSVs described in
`REPRODUCE.md`, with four exceptions that come from the credentialed Materials Project
pulls and are committed so that a clone without an API key can still run every phase that
reads them:

| File | Produced by | Notes |
|---|---|---|
| `mp_gga_raw.csv` | `q2_known_baseline.py` | 152,426 rows: `material_id`, `energy_above_hull`, `nelements`, `chemsys` for `thermo_types=GGA_GGA+U` |
| `mp_r2scan_raw.csv` | `q2_known_baseline.py` | the same fields for `thermo_types=r2SCAN` |
| `known_baseline.csv` | `q2_known_baseline.py` | per-cell flip rates for previously catalogued materials |
| `mp_completeness.csv` | `q2b_completeness.py` | per-material r²SCAN entry coverage of the chemical system and its subsystems |

Those four derive from the Materials Project API, retrieved 9–10 October 2026. The Materials
Project terms of use place downloaded content under the Creative Commons Attribution 4.0
licence and state that it "may be copied, distributed, transmitted, and adapted, without
obtaining specific permission, provided proper attribution is given to the Materials
Project". The same terms permit collecting large fractions of the database through the API
and presenting processed results with attribution, while prohibiting direct scraping of the
website; these extracts were obtained through the API. The required attribution:

> A. Jain, S. P. Ong, G. Hautier, W. Chen, W. D. Richards, S. Dacek, S. Cholia, D. Gunter,
> D. Skinner, G. Ceder and K. A. Persson, "Commentary: The Materials Project: A materials
> genome approach to accelerating materials innovation," *APL Materials* **1**, 011002
> (2013). doi:10.1063/1.4812323

The two GNoME input CSVs are not redistributed here and are governed by their own
licence. The GNoME repository releases its data under the Creative Commons
Attribution-NonCommercial 4.0 International licence (CC BY-NC 4.0) and its code under
Apache 2.0, verified at
<https://github.com/google-deepmind/materials_discovery> on 11 October 2026. The data are
used here for non-commercial research. This repository redistributes no GNoME records:
every GNoME-derived file in `results/` is an aggregate, the largest being 83 rows of
per-element summaries. The two large per-material files above are Materials Project
extracts, not GNoME rows.

The non-commercial clause is worth flagging rather than resolving here. The paper is signed
from a company affiliation, and any commercial use of these data would need permission from
the dataset's authors. Nothing in this repository is a legal opinion.

Note that the repository's MIT licence covers this repository's own code and derived
results. It does not and cannot grant rights to third-party data: the four files above are
governed by the Materials Project terms quoted here, and the GNoME inputs by CC BY-NC 4.0.

Everything else in this directory is a derived result of this repository's own code and is
covered by the repository's MIT licence. `run_all.py` deletes and regenerates all of it
except the four files above; `.github/workflows/reproduce.yml` does the same on a clean
runner, which is why the four are named as exemptions there.

When a run skips the two credentialed phases, every headline check that reads their output
is printed with the suffix `[stored, not regenerated here]`, so a partial run cannot be
mistaken for a full one.
